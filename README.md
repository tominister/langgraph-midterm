# 🧠 Document QA App (Flan-T5 + Qdrant + Flask)

This is a simple Document Question Answering (RAG) web app. It allows you to upload PDF/TXT files, index them, and ask questions. The app retrieves relevant chunks using embeddings and answers using Flan-T5.

---

## 🚀 Features

- 📄 Upload and manage PDF or TXT documents  
- 🔍 Index documents into a Qdrant vector store  
- ❓ Ask questions and get answers from the indexed content  
- 🧠 Embeddings via `all-MiniLM-L6-v2`  
- 🤖 Answers generated by `Flan-T5` (`google/flan-t5-xl`)  
- 🌐 Simple web UI via Flask  

---

## 🛠 Setup Instructions

### 1. Clone the Repo

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```

### 2. Install Python Packages

> Make sure you’re using Python 3.8 or later.

```bash
pip install -r requirements.txt
```

### 3. Run Qdrant (Optional: via Docker)

If you're using local Qdrant:

```bash
docker run -p 6333:6333 qdrant/qdrant
```

Or use [Qdrant Cloud](https://qdrant.tech/cloud/) and update the host in `rag.py`.

---

### 4. Start the App

```bash
python app.py
```

Then go to: [http://127.0.0.1:5000](http://127.0.0.1:5000)
